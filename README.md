# GlobeFront preview

The built files of a test preview of GlobeFront, for friends to try. It is not the launch site, and the source is not
published here. The site asks for a password; the news snapshot is encrypted with it.

- News: a snapshot of headlines indexed by [the GDELT Project](https://www.gdeltproject.org/), last checked 2026-11-24T03:00:56Z. It
  does not update by itself. Headlines and links belong to their outlets.
- Map data and imagery: the credits are on the map (the © button).
- Fonts: IBM Plex and Source Serif 4, SIL Open Font License 1.1 (`licences/` and `map/fonts/`).
